Cara Membagikan Web Ujian Ini

Aplikasi web ini bersifat Single-File Web App. Anda dapat meng-host file HTML ini secara 100% gratis agar siswa dapat mengaksesnya melalui browser HP / Laptop masing-masing:

Opsi 1: GitHub Pages (Gratis & Mudah) 1. Buat repository baru di GitHub.
2. Upload file index.html ini.
3. Buka Settings -> Pages -> Pilih branch main -> Save.
4. Bagikan URL yang dihasilkan ke siswa.
Opsi 2: Netlify Drop / Vercel 1. Buka app.netlify.com/drop
2. Drag & Drop folder berisi file HTML ini.
3. Dapatkan Link siap pakai dalam 5 detik.
Catatan Realtime: Fitur realtime antar tab bekerja otomatis di domain/perangkat yang sama. Untuk skala antar jaringan (server online), web ini siap dihubungkan ke Firebase / Supabase.
